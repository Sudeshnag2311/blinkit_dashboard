
# Blinkit Sales Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive sales analysis dashboard for Blinkit, India's last-minute grocery delivery platform. The dashboard was created using Microsoft Power BI to analyze sales performance, customer ratings, product categories, and outlet characteristics.

## Objectives
- Analyze total sales and average sales.
- Understand customer ratings and item distribution.
- Compare sales across outlet sizes and identifiers.
- Explore sales trends by outlet establishment year.
- Use interactive filters to investigate different product and outlet segments.

## Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **CSV/Excel** – Dataset source, where applicable

## Key Performance Indicators (KPIs)
- **Total Sales:** 2.31K
- **Average Sales:** 144.42
- **Average Rating:** 3.50
- **Number of Items:** 16

*Note: These figures reflect the values displayed in the current dashboard and may depend on the selected filters.*

## Dashboard Features
- KPI cards for key business metrics.
- Sales trend analysis by outlet establishment year.
- Sales comparison by outlet size and outlet identifier.
- Average sales analysis by item type.
- Product and outlet segmentation.
- Interactive filters for outlet location tier, outlet size, and item type.

## Insights
- The dashboard provides a quick overview of sales performance through KPI cards.
- Outlet comparisons help identify differences in sales across outlet segments.
- Item-type analysis helps compare average sales among product categories.
- Interactive filters allow users to explore the data from different perspectives.

*These are dashboard analysis capabilities, not claims of independently verified business findings.*
